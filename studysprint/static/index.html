About this project

Although Study Sprint is a simple web app, it showcases a complete agentic workflow. Pick any subject and grade, and five Claude agents build a fact-checked lesson (three concepts, a diagram and a 5-question quiz) while a 1-minute timer triggers movement breaks.

  • Multi-agent coordination: Intake, Curriculum, Diagram, Quiz and Reviewer agents hand work to each other, with the diagram and quiz written in parallel.
  • A harness: code runs the agents, checks every hand-off, sends rejected work back for revision, and caps tokens and cost.
  • Fact-checking: an independent Reviewer agent checks each lesson and can send it back up to twice.
  • Guardrails: a topic gate before any agent runs, reading levels measured by code, a sanitizer for agent-drawn diagrams, and grading on the server.
  • Evals: over 200 automated tests, a 45-case red-team and a live test matrix from Kindergarten to College.
  • Hooks: a Claude Code hook checks every file write and shell command while the project is built, blocking deletions and writes outside the project.
  • Claude Code, GitHub and Render working together: built with Claude Code, tested by GitHub Actions on every push, and deployed to Render from a Blueprint.
